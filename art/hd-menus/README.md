# HD menu sources

20 active masters cover 19 menu/dialog layouts and the retained surround source.
17 continuous widescreen board masters are in `masters-wide`; dialog and
surround masters are in `masters`. Runtime crops, animated light signals and
18 outline-font atlases are recorded in the 932-image pack manifest.

Original `.anm` definitions and their frame sources are recorded by hash; they
must come from the original game data when re-exporting. Precise generated
geometry versus inherited animation signals still needs visual review.

See [the combined artwork guide](../README.md).
