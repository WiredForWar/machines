# Static startup-card sources

Four active masters and the exact retained generation prompts cover `acclaim`,
`charlogo`, `legal` and `wait`. Each returned master is 1448x1086. Runtime
variants extend through 3840x2880; those dimensions describe resampled exports,
not additional generated source detail. The pack has 24 PNGs and one bootstrap
BMP, plus a small marker identifying the engine-drawn loading-bar outline.

No movie, soundtrack or original game binary is included. See
[the combined artwork guide](../README.md).
