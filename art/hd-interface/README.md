# Additional interface artwork

896 source families, 827 distinct reference visuals and 32 master atlases.
Identical reference images share generated artwork but retain their original
runtime filenames. The pack exports 3,584 registered images at 1x–4x.

The source manifest records source hashes, logical image dimensions, atlas
positions and crop rectangles. Fixed canvas registration is retained for
animation frames; trimming and independently centering the unfolding weapon
panels would break their sequence.

The cursor sheet `cursors-large-02` includes a targeted transparency correction;
its active master and correction prompt are retained. The rejected opaque
variant is not part of this contribution.

See [the combined artwork guide](../README.md) for installation, reproduction,
coverage and interactive-review limits.
