# HD HUD sources

31 active generated masters and their prompts, the source/crop manifest and
font-layout metadata are retained here. The runtime pack contains 984 images.
Five compatible font families retain all 256 byte positions and original glyph
advances. The nine gameplay symbol meanings are documented in
[SYMBOL_SEMANTICS.md](SYMBOL_SEMANTICS.md).

See [the combined artwork guide](../README.md) for previews, installation,
reproduction and validation limits.
